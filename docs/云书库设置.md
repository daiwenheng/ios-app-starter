# 云书库设置(只做一次)

做完之后:你(管理员)可以把书传到云书库,别人打开你的网页就能看到这些书,并加到自己的书架里读。别人不能上传或删除。

1. 打开 https://supabase.com ,用 GitHub 账号登录,点 **New project**,随便起个名字,设一个数据库密码(记不记都行),地区选离你近的(如 Singapore / Tokyo),等一两分钟创建完成。
2. 左边点 **SQL Editor** → New query,把 `supabase-setup.sql` 的全部内容粘进去,点 **Run**。
3. 左边点 **Authentication** → **Sign In / Providers**(或 Settings),把 **Allow new users to sign up** 关掉,这样没人能自己注册。
4. 左边 **Authentication** → **Users** → **Add user** → Create new user,填你自己的邮箱和密码,勾上 Auto Confirm User。这就是管理员账号。
5. 左边 **Project Settings** → **API**,复制 **Project URL** 和 **anon public** 这个 key。
6. 把这两样发给我(它们本来就是公开的,没关系),我填进 `docs/config.js`。密码不要发给我。
